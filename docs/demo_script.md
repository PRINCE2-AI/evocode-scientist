# Demo Script

1. Run `python demo.py`.
2. Show the selected benchmark problem.
3. Explain that every candidate is validated, executed, scored, and stored.
4. Open the best candidate code.
5. Show the leaderboard in Streamlit with `streamlit run app/ui.py`.

Short pitch:

> I built an AlphaEvolve-inspired coding agent that does not just generate code. It executes candidates in a restricted sandbox, scores them with benchmark tests, stores lineage in SQLite, and evolves the best programs across generations.
